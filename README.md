# Magaji K. Ibrahim — Portfolio Website

This package is based on the CV previously shared by Magaji K. Ibrahim, with an additional section for current AI automation and software-learning projects.

## Files
- `index.html` — responsive one-page portfolio website
- `Magaji_K_Ibrahim_CV.pdf` — CV PDF linked from the website
- `README.md` — publishing instructions

## Preview
Open `index.html` in a browser. The website has no build step or third-party dependencies.

## Publish with GitHub Pages
1. Create a public GitHub repository, for example `magaji-portfolio`.
2. Upload all three files to the repository root.
3. In the repository, open **Settings → Pages**.
4. Select **Deploy from a branch**, choose branch `main` and folder `/ (root)`, then save.
5. Wait for GitHub Pages to show the published website address.
